Git was a huge step forward in source code management when it first came on the scene. One big thing was, for example, that you no longer had to be connected to some server to commit code. But git had another huge thing going for it and that was github.com. (When I signed up for github in 2008, I thought git and github were the same thing / by the same people.) Github abstracted some of the complexity away from git, but more than anything it was great because Github was a public place to host and showcase projects, and invite random people I'd meet on the internet so we could help each other out. I created an account early on and started going all in on to git—and Github. In the early years, say 2008-2011, Github was constantly adding neat things like issue tracking, wikis and then-new social stuff like starring / following other people and their work. It started to feel like a community that I could learn from and contribute to.

FF 16 years and Github is not only the de facto standard place to host and discuss OSS software, but it has added many things developers need or didn't know they needed but now do need: discussions, CI/CD workflows, vulnerability monitoring, teams and organizations, code sandboxes, and now f*ing AI. This may seem cool at first glance. Most of these things work extremely well and are offered at no $ cost. This is possible in part because github has the power of one of the largest and most enshittified tech companies on the globe behind it. (Microsoft purchased github in 2018 for 7.5 billion dollars.)

We *do* pay, however. The switching cost for OSS devs has become near unbearable. A codebase managed by git is perfectly portable and doesn't care where it's hosted. But Github has achieved what is the holy grail of any social platform: network effects. The gravity of the community becomes so big that it is hard to escape or ignore. Sure, you can host your project on Gitlab or Codeberg or wherever else, but far fewer people will know about it, use it, give you feedback, or contribute. If you *are* on Github like, well, almost anyone working with OSS, you can't leave unless you're okay with pretty much pulling the plug on that community and working on your own. Even niche technical communities like OpenStreetMap (OSM) are relying more and more on github to build community around the codebases they maintain. (I have been a part of the OSM community for a long time and I am part of the problem. My main OSM-related project, MapRoulette, is hosted on github and will continue to be—I can't afford to leave.)

Community is what makes OSS tick! It is unacceptable that one of the largest tech companies in the world got to own it.  And by owning Github, Microsoft gets to dictate how we interact with and reason about our code. This is only exacerbated by the almost-universal adoption of VS Code.
